# FenotIT - Phenotypic Color Analysis Tool

![Version](https://img.shields.io/badge/version-1.0.0-blue) ![License](https://img.shields.io/badge/license-CC--BY--NC--SA--4.0-green) ![Platform](https://img.shields.io/badge/platform-Windows%2010%2B-lightgrey)

Desktop tool for extracting and analyzing dominant colors in biological images using K-means clustering.

**Developed by:** Physiology Team, Bean Breeding Program  
**Alliance of Bioversity International and CIAT** | Palmira, Colombia

---

## Quick Start

### Installation
1. Extract `FenotIT_v1.0.0_win64.zip`
2. Run `FenotIT.exe` (no installation needed)
3. Windows 10/11 (64-bit) | 4GB RAM minimum

### Usage
1. Load images
2. Draw polygons (left-click points, right-click to close)
3. Select number of colors (1-10)
4. Process and export CSV + visualizations
5. Run the EMD math

---

## Features

- Interactive polygon selection
- K-means color clustering (1-10 colors)
- RGB, HEX, luminosity analysis
- Batch processing
- CSV + PNG exports
- Zoom, pan, navigate
- EMD Algoritm for color comparision.
- 100% local processing (no internet)
