# Changelog

## [1.0.0] - 2025-01-20

### Initial Release

**Core Features:**
- Interactive polygon selection
- K-means clustering (1-10 colors)
- RGB, HEX, luminosity analysis
- Batch processing
- CSV + PNG visualization exports
- Zoom, pan, navigation controls
- Editable object names

**Platform:** Windows 10/11 (64-bit)

**Dependencies:** Python 3.11, OpenCV 4.11, NumPy 1.24, scikit-learn 1.3, Matplotlib 3.8
